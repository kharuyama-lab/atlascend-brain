ATLASCEND Brainは大学教育向けのインタラクティブ3D教材です。オリジナルのBrain Projectおよび複数の公開解剖・医用画像データを基に、教育用の表示・解説・機能を追加した派生教材です。以下の帰属表示は、開発元による本教材の推薦・承認を意味しません。

1. 原著作物とプログラム / Original application

Brain Project — Itay Inbar
原版: GitHub / brainproject
ビューアのソースコードに関するライセンス通知: LICENSE (Apache License 2.0)

ATLASCEND版では日本語表示、教育用解説、神経伝導路・脊髄・血管障害・医用画像に関する機能とUIを拡張しています。各追加部分の権利条件は、元データの権利条件と区別して扱います。

2. 脳・深部構造の3Dモデル / Brain anatomy

brain.glbおよび関連メタデータは、元のBrain Projectによる表示に従いCC BY-SA 4.0の対象として取り扱います。原データ・派生モデルの表示は LICENSE を参照してください。

主要出典: Z-Anatomy、BodyParts3D / DBCLS。深部核などにはCIT168、Najdenovskaら、Neudorferらのアトラス由来データが含まれます。個別の出典・条件については元のLICENSEをご確認ください。CC BY-SA 4.0 ライセンス

3. 頸髄3Dモデル / Cervical spinal cord

頸髄外形モデルはBodyParts3D / DBCLS由来のOrganUIモデルを加工し、脳幹モデルに幾何学的に位置合わせしています。原モデルの表記に従いCC BY-SA 2.1 Japanとして別途帰属表示を維持します。

モデルの帰属・加工内容 · CC BY-SA 2.1 Japan · OrganUI

4. CT / MRI・MRIテンプレート

Mode 3のCT/MRIサンプルデータは 3D Slicer のCT-MR Brain SampleDataに基づきます。別途ICBM152 2009c MRIテンプレートを使用する場合、その配布元の著作権・引用条件が適用されます。元データの権利・利用条件と、当教材のコードのライセンスは同一ではありません。

資料: 3D Slicer SampleData · ICBM152 2009c

5. 教材上の制限 / Educational limitations

本教材は解剖学・神経理学療法の教育用であり、診断、治療計画、手術ナビゲーションには使用できません。深部構造・伝導路は参照アトラスから位置合わせされた近似形状を含みます。CT/MRIと元の3D解剖メッシュ間の厳密な位置合わせは完了していません。模式的な脊髄断面・病変表示を患者固有の解剖所見として解釈しないでください。
